# DNA rubric — RocketMinds (example)

Binary rules. The builder must satisfy every line; the human uses the same list to judge
the candidates. Derived from the curated exemplar DNA (see `exemplars/INDEX.md`). Generic
craft rules apply to every brand; brand-specific rules are marked `[RM]`.

## Craft (every brand)
- [ ] One signature accent, used sparingly; never a rainbow.
- [ ] Spacing and type carry the design; zero decorative noise.
- [ ] The product/output is the hero, not marketing chrome.
- [ ] Negative space is used on purpose and balanced; no half-empty dead zones.
- [ ] Confident CTAs; no urgency or hype language.
- [ ] Clear type hierarchy; one idea per line; no orphan words.
- [ ] AA contrast minimum on every text/background pair.
- [ ] Real imagery only when it beats clean type and matches the brand; otherwise type + space.

## Composition (judged by the human; the machine cannot see these)
- [ ] The strongest beats sit FIRST and LAST, not buried mid-page (serial position + peak-end).
- [ ] Exactly ONE element is deliberately dominant; everything else defers to it (Von Restorff).
- [ ] Related items read as a set through proximity, shared styling or a shared container (Gestalt).
- [ ] Each decision point offers few, clear options; no choice set beyond ~7 (Hick + Miller).
- [ ] Conventional patterns are reused, not reinvented, wherever the user already has expectations (Jakob).

## [RM] brand
- [ ] Dark-native by default.
- [ ] Voice routed through `rocketminds-brand-voice`; no invented metrics or testimonials.
- [ ] No em dashes in copy; periods and semicolons instead.
