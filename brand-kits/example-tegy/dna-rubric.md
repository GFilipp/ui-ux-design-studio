# DNA rubric — Tegy (example, derived from the live design system)

Shared craft rules apply (see `example-rocketminds/dna-rubric.md`): one accent used sparingly;
type + space carry the design; product/output is the hero; no dead zones; confident CTAs, no
urgency language; one idea per line, no orphans; AA contrast; clean type first.

## [Tegy] brand
- [ ] **Dark warm-native.** Near-black `#171312` (warm, not pure black); flat surfaces, thin 1px borders.
- [ ] **Editorial-technical type pairing.** Lora serif display headlines over Space Mono body — the serif/mono contrast IS the identity. Mono for eyebrows, labels, buttons.
- [ ] **One orange primary `#fe6c2d`, used sparingly** (CTAs, key accents, index numbers). Teal `#38bbc7` is a sparse secondary only. Everything else neutral.
- [ ] **Blueprint motif.** Thin low-opacity grid lines, diamonds, and squares as structural background; technical, not decorative. Never busy.
- [ ] **Mono eyebrows/labels UPPERCASE, wide tracking** (0.16-0.24em). This is the signature label treatment.
- [ ] **Sharp corners.** Buttons and cards have no border-radius. Do not round them.
- [ ] **Motion is subtle.** Reveal-on-scroll only; respect `prefers-reduced-motion`. Scroll is state, not spectacle.
- [ ] **Voice = rocketminds-brand-voice.** Direct, candid, no hype, no em dashes, proof-gated.
